# Document types

| Artifact | Purpose | Lifecycle |
|---|---|---|
| PRD | Product intent, scope, acceptance | Update current state |
| Impact Analysis | Determine affected domains | Per change |
| Tech Spec | Implementation/system design | Per significant change |
| RFC | Proposal requiring discussion | Historical |
| ADR | Final architecture decision | Historical, supersede |
| API Design | Contract change | Update current + per change |
| DB Design | Schema/data change | Update current + per change |
| Security Review | Threat/permission/secrets impact | Per relevant change |
| Test Plan | Verification strategy | Per change |
| Release Plan | Deployment/rollback | Per release/change |
| Runbook | Repeated operational procedure | Update current state |
| Incident | Incident timeline/impact | Historical |
| Postmortem | Root cause/corrective actions | Historical |
